# Cozine website

This repository contains the files for [cozine.xyz](https://cozine.xyz).

Cozine is a Discord bot that helps server owners spot Roblox exploiters and cheaters. The site has information about the bot, its status, and the rules for using it.

## Pages on the site

- [Home](https://cozine.xyz/) – overview of Cozine
- [Privacy Policy](https://cozine.xyz/privacy/) – what data is collected and how it’s handled
- [Terms of Service](https://cozine.xyz/tos/) – rules for using Cozine
- [API Terms of Service](https://cozine.xyz/api-tos/) – rules for using the Cozine API

## Links

## Status label

The status shown on the site comes from [`static/status.txt`](static/status.txt). it indicates if the site is in production, beta, updating or broken.
The website is currently in beta so nothing applies to the main bot currently.
