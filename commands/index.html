Commands How it works Changelog

Last Updated: November 15, 2026

Cozine provides Discord slash commands and moderation tools to help server staff identify flagged Roblox exploiters and manage alerts. Available commands and features may vary by access level, server setup, and beta status.

Core Commands

  • /skid — Scan a Discord user to check for linked Roblox activity and flagged exploiter records known to Cozine. Results and available details depend on your access level and privacy/settings preferences.
  • /privacy — Manage your privacy preferences for command error logging, including whether Cozine should send diagnostic logs and whether your user ID may be included when logging is enabled.
  • /info — View information about Cozine and how to use it.
  • /credits — View credits and acknowledgements.
  • /feedback — Send feedback to the Cozine team.

Server & Moderation Tools

  • /trace — Guild moderation tool for cross-referencing/checking users in your server context (available to authorized server staff where enabled).
  • /trace_setup — Configure trace/alert delivery for your server (for example, where Cozine should send notifications). Requires appropriate server permissions.
  • /trace_setup_clear — Clear/remove trace setup configuration for your server.
  • Scan user (context menu) — Right-click/user context action to quickly scan a member where available.

Join Alerts & Actions

When configured, Cozine can check members against its registry and notify moderators when a flagged user joins. Depending on your server setup, you can use alert-only workflows or enable automated moderation actions supported by Cozine. Always review alerts and follow your server’s moderation policies and our Terms of Service.

Permissions & Access

  • Some commands require server permissions, Cozine access/eligibility, or Exclusive access.
  • Exclusive features may include broader scan coverage, lower cooldowns, and additional scan modes/details (see homepage FAQ).
  • Cozine is in beta; commands and behavior may change over time.
