Privacy Policy Terms of Service TOS - API

Last Updated: September 12, 2026

By using the Cozine API, you agree to our main Terms of Service plus the additional terms below. If you don't agree, don't use it.

1. Access

API access is not open to everyone. API keys are granted on request (see Contact below). We review requests individually and can deny or revoke access for any reason. There is no payment involved - access is granted at our discretion.

2. Keys

  • Your key is tied to your Discord account. Do not share it.
  • If your key is leaked or compromised, notify us immediately so we can rotate it.
  • Sharing, selling, or publicly posting your key may result in immediate revocation of access.

3. Rate Limits

  • Every key has a request limit. If you exceed it, you will receive a 429 response and must wait before making more requests.
  • Deliberately bypassing limits (for example, by using multiple keys or distributing requests across accounts) may result in access being revoked.

4. Permitted Use

  • Access data for your own guilds
  • Look up user records for legitimate moderation purposes
  • Build tools or integrations that comply with these terms and our other policies

5. Prohibited Use

  • Bulk scraping or exporting data for unrelated purposes
  • Reselling or redistributing the data
  • Using the API to target, harass, dox, or harm anyone
  • Attempting to reverse engineer or bypass the API or its protections
  • Using the API for purposes other than legitimate moderation and safety

6. Data

  • We don't sell your data.
  • For data deletion and appeals, see our Privacy Policy

7. Downtime & Liability

The API may experience downtime or interruptions. We are not liable for:

  • Outages, delays, or slow responses
  • Issues with tools or services you build that are affected by an outage or change

8. Termination

We may revoke or suspend your API access at any time if you violate these terms. If you believe a decision was made in error, you can contact us (see Contact below).

9. Changes

We may update these terms at any time. If there are significant changes, we will post an announcement in the support server. Continued use of the API after changes take effect constitutes acceptance of the updated terms.

10. Contact

To request an API key, dispute a decision, or ask anything: support server or open a support ticket in the panel.
