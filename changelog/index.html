Commands How it works Changelog

Last Updated: November 15, 2026

Cozine is in beta and actively evolving. This page tracks notable updates to the bot, website, and panel.

v1.0.0 — Beta (November 2026)

  • Website & panel beta: Launched the Cozine website and web panel experience for viewing plans/cooldowns, scan history, and managing preferences (where available).
  • Discord login & sessions: Panel sign-in via Discord OAuth with secure session handling and configurable session lifetime.
  • Privacy controls: Added/updated /privacy preferences for command error logging, including options to control diagnostic log sending and user ID inclusion; updated privacy policy to explain server-side error logs and deletion requests.
  • Moderation & scanning: Continued improvements to scan workflows, alerts/setup tools, and panel/server management features during beta.
  • Website improvements: Added static, crawlable legal pages, SEO/meta updates, embed previews, and new documentation pages (commands, how it works, changelog) with sitemap updates.

Earlier updates
