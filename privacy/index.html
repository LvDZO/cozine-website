Privacy Policy

Privacy Policy Terms of Service TOS - API

Last Updated: November 13, 2026

By using Cozine, you agree to this Privacy Policy and our Terms of Service. Please read both documents carefully. If you do not agree, do not install or use the bot.

1. How We Collect Information

All information is collected through public data and platform integration:

  • Discord Platform Data - We access publicly accessible member data, presence information, and shared security logs within monitored servers.
  • Roblox Public API - Public profile information to verify Roblox account status.
  • Account Linking Services - Third-party services that link Roblox accounts to Discord identities.

2. What We Collect

  • User IDs - Unique Discord identifiers
  • Guild IDs - Server identifiers
  • Roblox Account IDs - Unique Roblox identifiers linked to documented activity
  • Security Logs - Records of violations and exploit activity

3. How We Use Data

Data is used strictly to keep communities safe and identify users in violation of Discord or Roblox Terms of Service. This includes:

  • Checking new members against records of verified ToS violators
  • Sending alerts to moderators about potential threats
  • Keeping records of security violations

4. Command Error Logs

When a command fails, Cozine may collect error logs to help improve the bot and fix bugs. These logs are stored server side on our own infrastructure and are only used to diagnose and fix bugs in Cozine , they are never used for profiling, marketing, or shared with third parties.

Logs can contain error details and, if you choose, your Discord user ID. You can turn error logging on or off at any time using the /privacy command. The same command also lets you choose whether your user ID is included in error logs when logging is enabled. Error logs are deleted on request thru the support server or by creating a ticket in the panel.

5. Age Requirement

Discord requires users to be at least 13 years old. We do not verify age and do not ask for it. If we learn that a user is under 13, we will terminate them from using our services and delete their data from our systems, including security logs and error logs, unless we are legally required to keep it.

6. Data Retention & Deletion

We will delete your data upon request. We retain records of users documented to have violated Discord or Roblox Terms of Service, so that repeat offenders can be detected. These records are kept for up to 24 months from the most recent documented violation, after which we check whether the record is still needed and delete it if it is not. If you believe you were flagged in error, you can file an appeal (see Contact below) and we will review your case. If an appeal is approved, one of two things happens, depending on the case:
Data deletion: the record is deleted and the user is no longer flagged.
Whitelist: the user is whitelisted, the record is kept, and the user may use the bot. Whitelisting is at the discretion of the bot owners.

We recognize that security researchers or investigators may occasionally be flagged. If you believe your data was logged in error, you can easily file an appeal (see Contact below). Each case is reviewed manually.

7. Data Retention Periods

  • Flagged-user records - Kept for up to 24 months from the most recent documented violation, then checked and deleted if no longer needed. Deleted earlier if a successful appeal is granted or if we learn the user is under 13.
  • Whitelisted records - Kept until the bot owners remove the whitelist. Whitelisted users may still trigger alerts to servers that have set up Cozine.
  • Security logs - Kept while relevant to moderation and open appeals.
  • Command error logs - Kept only while relevant to fixing bugs, and deleted on request.

8. Data Storage

  • Stored on secure servers with restricted access
  • Access is strictly limited to bot administrators
  • We may share your data with third parties only for the purposes described in this policy here, and we will never sell it.

9. Contact

For questions, data deletion requests, or to file an appeal, join our support server or open a support ticket in the panel.
